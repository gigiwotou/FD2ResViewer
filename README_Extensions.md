# 炎龙骑士团II资源分析器 - 功能扩展指南

## 当前实现状态

### ✅ 已完全实现的功能

#### 1. FDOTHER.DAT 文件分析 ⭐ 新增
- **描述**: 混合资源文件，包含多种类型的图像数据
- **功能**: 
  - 104个主分类的数据解析
  - 多种子类型图像生成（面部、形状、字体、背景等）
  - 自动识别不同数据格式并应用相应的解码算法
  - **新增**: 现已集成到fd2_analyzer.py中，支持批量处理
- **输出**: fdother_[类型]_[主索引]_[子索引].png 格式的图像文件
- **使用方法**: 
  ```bash
  python fd2_analyzer.py FDOTHER.DAT -o output_dir
  ```

#### 2. FDICON.B24 文件分析  
- **描述**: 人物图标资源文件
- **功能**:
  - 1680个24x24像素人物图标提取
  - 调色板渲染支持
- **输出**: icon_XXXXX.png 格式的图标文件
- **使用方法**: 
  ```bash
  python fd2_analyzer.py FDICON.B24 -o output_dir
  ```

#### 3. DATO.DAT 文件分析
- **描述**: 人物表情资源文件  
- **功能**:
  - 137个角色 × 4种表情的面部图像提取
  - RLE压缩格式解码
- **输出**: face_XXXX_X.png 格式的表情文件
- **使用方法**: 
  ```bash
  python fd2_analyzer.py DATO.DAT -o output_dir
  ```

#### 4. BG.DAT 文件分析
- **描述**: 战斗背景资源文件
- **功能**:
  - 56个战斗背景图像提取
  - 复杂RLE压缩算法解码
- **输出**: bg_XXX.png 格式的背景文件
- **使用方法**: 
  ```bash
  python fd2_analyzer.py BG.DAT -o output_dir
  ```

### 🛠️ 批量处理功能

fd2_analyzer.py 现在支持批量处理多个文件：

```bash
# 批量处理目录中的所有支持文件
python fd2_analyzer.py -b 目录路径 -o output_dir

# 例子：处理当前目录的所有DAT文件
python fd2_analyzer.py -b . -o all_images
```

## 技术特性

### 图像处理算法
- **调色板系统**: 支持3种不同的调色板（灰阶、蓝色系、红色系）
- **压缩格式支持**:
  - RLE压缩（面部图像、背景图像）
  - 自定义形状压缩（形状数据）
  - 位图压缩（字体数据）

### 数据结构解析
- **索引表解析**: 自动解析各种复杂的索引结构
- **多级嵌套**: 支持主分类-子分类的嵌套数据结构
- **错误处理**: 对损坏或异常数据的容错处理

## 使用示例

### 基础用法
```bash
# 分析单个文件
python fd2_analyzer.py FDOTHER.DAT

# 指定输出目录
python fd2_analyzer.py FDICON.B24 -o extracted_icons

# 批量分析目录中的所有文件
python fd2_analyzer.py /path/to/fd2/data/ -b
```

### 原版main.py用法
```bash
# 只支持FDOTHER.DAT
python main.py FDOTHER.DAT
```

## 扩展建议

### 优先级高的功能
1. **FDSHAP.DAT**: 包含大量UI元素和道具图标
2. **FDTXT.DAT**: 可以提取游戏的所有文本内容
3. **FDFIELD.DAT**: 战场地图对游戏研究很有价值

### 优先级中等的功能  
1. **FIGANI.DAT**: 动作序列比较复杂，但很有趣
2. **批量处理优化**: 提升大文件处理速度
3. **GUI界面**: 类似原版C#程序的图形界面

### 可选功能
1. **动画生成**: 将动作序列合成为GIF
2. **地图编辑**: 支持战场地图的修改和重新打包
3. **资源替换**: 支持将提取的资源重新打包回游戏

## 代码结构

### 当前文件说明
- **main.py**: 基础版本，只支持FDOTHER.DAT
- **fd2_analyzer.py**: 扩展版本，支持多种文件格式
- **resviewer_src/**: C#原版源码参考

### 核心类说明
- **Main**: 基础分析器类
- **FD2Analyzer**: 扩展分析器类
- **BMPMaker**: 图像生成器
- **ColorPanel**: 调色板管理器
- **DataBlock**: 数据块结构
